Gambaran besar

Stack yang direkomendasikan

Aplikasi

PWA (web app yang bisa di-install)

Satu kode untuk HP dan web. Di HP muncul ikon logo Mbo Suti di layar utama, tanpa Play Store. Dibangun dengan React/Vite atau SvelteKit.

Backend

Supabase

Login, database Postgres, dan realtime dalam satu layanan. Paket gratis cukup untuk 1 warung (500 MB data, 50 ribu pengguna aktif).

Hosting

Vercel / Netlify

Gratis, HTTPS otomatis, deploy dari GitHub setiap ada perubahan.

Cetak

Struk 58/80 mm

Laptop: window.print dengan CSS ukuran struk. HP Android: Web Bluetooth ke printer thermal ESC/POS, atau lewat app RawBT sebagai jembatan.

Ekspor

XLSX + CSV + Sheets

SheetJS untuk file Excel di browser. CSV untuk import ke Google Sheets. Sinkron otomatis ke Sheets lewat fungsi terjadwal (opsional).

Offline

Tetap jalan saat sinyal hilang

Transaksi disimpan di HP dulu (IndexedDB), lalu dikirim begitu online lagi. Penting untuk warung dengan sinyal naik-turun.

Alur penting

Admin update stok → kasir ikut berubah

  1. Admin simpan stok masuk.
  2. Database menambah angka di tabel stok.
  3. Supabase Realtime mengirim perubahan ke semua HP yang sedang buka (di bawah 1 detik).
  4. Layar kasir memperbarui angka tanpa refresh, indikator "Live" berkedip.

Penjualan → stok & laporan

  1. Kasir tekan Selesai.
  2. Satu fungsi database menyimpan transaksi, pembayaran, dan memotong stok sekaligus (tidak bisa setengah jalan).
  3. Stok baru tersebar ke HP lain.
  4. Laba rugi, neraca, dan buku kas langsung terhitung dari data yang sama.

Yang perlu diputuskan

1. Stok dihitung per menu atau per bahan?Per menu (porsi siap jual) lebih simpel dan cocok untuk warung. Per bahan (kacang, beras, telur) lebih akurat untuk HPP tapi perlu resep per menu.
2. Printer yang dipakai?Thermal Bluetooth 58 mm (paling umum, ±Rp 250–400 rb) atau USB/WiFi 80 mm di laptop.
3. QRIS statis atau dinamis?Statis: pakai QRIS warung yang sudah ada, kasir cek manual. Dinamis: lewat Midtrans/Xendit, status lunas otomatis, ada biaya ±0,7% per transaksi.
4. Backend Supabase oke?Alternatif: Firebase (mirip), atau Google Sheets sebagai database (murah tapi lambat dan rawan untuk realtime).
